# Website SEO Health Check — https://www.fallersfurniture.com/

## Executive Summary

This report covers technical and on-page SEO factors that can be verified
directly from the website's public HTML. It does not include traffic,
rankings, or backlink data — those require a paid tool and are marked
"NOT VERIFIED" below rather than estimated.

**6 issue(s) found.**

## Issues Found

### 1. Title tag too long — Severity: LOW
- **Evidence:** Title is 79 characters: "Furniture, Mattresses in Clarion, Shippenville and Knox PA | Faller's Furniture"
- **Recommended fix:** Shorten to under 60 characters so it doesn't get truncated in search results.
- **Confidence:** VERIFIED_FACT

### 2. Legacy <meta name="keywords"> tag present — Severity: LOW
- **Evidence:** Google has not used this tag as a ranking signal since 2009.
- **Recommended fix:** Safe to remove; not harmful, but signals the site hasn't had an SEO pass recently.
- **Confidence:** VERIFIED_FACT

### 3. H1 doesn't reinforce the title's target keyword — Severity: MEDIUM
- **Evidence:** H1: "Your home. your way. Since 1847" | Title: "Furniture, Mattresses in Clarion, Shippenville and Knox PA | Faller's Furniture"
- **Recommended fix:** Rework the H1 to include the same core keyword as the title tag.
- **Confidence:** ESTIMATE

### 4. Images missing alt text — Severity: MEDIUM
- **Evidence:** 1 of 1 <img> tags have no (or empty) alt attribute.
- **Recommended fix:** Add descriptive alt text to every product/content image for accessibility and image search.
- **Confidence:** VERIFIED_FACT

### 5. No structured data (schema.org) detected — Severity: MEDIUM
- **Evidence:** No <script type="application/ld+json"> blocks found in fetched HTML.
- **Recommended fix:** Add LocalBusiness/Organization schema so search engines can build rich results (hours, address, reviews).
- **Confidence:** ESTIMATE

### 6. Thin content on page — Severity: MEDIUM
- **Evidence:** Approximately 20 visible words detected on this page.
- **Recommended fix:** Expand with genuinely useful content (buying guides, FAQs) -- thin pages rank poorly.
- **Confidence:** ESTIMATE
